# Práctica – Datos y Algoritmos

Espacio de trabajo para la resolución de ejercicios de la materia. Cada ejercicio vive en su
propia carpeta `Ejercicio_NN/` con:

- `enunciado.md` — enunciado tal como fue provisto.
- `resolucion.md` — análisis, resolución paso a paso, explicación y conclusión.
- `diagrama.drawio` — solo si el ejercicio requiere representación gráfica (creado con el MCP de Draw.io).
