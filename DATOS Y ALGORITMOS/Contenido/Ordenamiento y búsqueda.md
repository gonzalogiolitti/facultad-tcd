Datos y Algoritmos 
Práctica Arreglos – Ordenamiento y 
búsqueda 
 
Ordenamiento Burbuja:  
1. Dado un arreglo de números enteros, ordena los números de menor a mayor utilizando 
el algoritmo de ordenamiento burbuja.  
2. Ordena en forma descendente una lista de palabras utilizando el algoritmo de 
ordenamiento burbuja.  
3. Desarrolla un programa que ordene una lista de enteros de manera ascendente 
utilizando el algoritmo de ordenamiento burbuja. Luego, muestra el número más grande y 
el más pequeño.  
4. Escribe un programa que ordene una lista de enteros en orden descendente utilizando el 
algoritmo de ordenamiento burbuja. Luego, calcula la suma de todos los números.  
 
Ordenamiento por Selección del Mínimo:  
6. Ordena una lista de números enteros de menor a mayor utilizando el algoritmo de 
selección del mínimo.  
7. Ordena en orden descendente un arreglo de nombres utilizando el algoritmo de 
selección del mínimo.  
8. Desarrolla un programa que ordene un conjunto de números reales en orden ascendente 
utilizando el algoritmo de selección del mínimo.  
9. Escribe un programa que ordene una lista de enteros en orden ascendente utilizando el 
algoritmo de selección del mínimo. Luego, muestra el número más grande y el más 
pequeño.  
10. Implementa un programa que ordene una lista de enteros en orden descendente 
utilizando el algoritmo de selección del mínimo. Luego, calcula la suma de todos los 
números.
