3. Promedio de elementos: Crea un programa que pida al usuario ingresar 8 números 
enteros en un arreglo unidimensional y luego calcule y muestre el promedio de esos 
números. 
 
4. Buscar un valor especíﬁco: Escribe un programa que permita al usuario ingresar 7 
números enteros y luego solicite al usuario un valor para buscar en el array. El 
programa deberá indicar si el valor está presente en el array o no. 
 
5. Inicializar y mostrar una matriz: Solicita al usuario que ingrese los elementos de 
una matriz 3x3 y luego muestra la matriz completa en pantalla. 
 
6. Suma de elementos por ﬁla: Crea un programa que solicite al usuario ingresar los 
elementos de una matriz 2x3 y luego calcule la suma de los elementos de cada ﬁla 
por separado, mostrando los resultados.  
 
7. Promedio de elementos por columna: Escribe un programa que pida al usuario 
ingresar los elementos de una matriz 3x4 y luego calcule el promedio de los 
elementos de cada columna, mostrando los resultados. 
 
8.  Buscar un valor especíﬁco: Desarrolla un programa que permita al usuario 
ingresar los elementos de una matriz 2x2 y luego pregunte al usuario por un valor 
especíﬁco para buscar en la matriz. El programa deberá indicar si el valor está 
presente en la matriz o no.  
 
9. Traspuesta de una matriz: Crea un programa que solicite al usuario ingresar los  
elementos de una matriz cuadrada 3x3 y luego calcule e imprima la traspuesta de
