Buenos días, esta es una clase de la Tegucatura de Ciencia de Datos con respecto a la configuración de base de datos no SQL para el uso de nuestros entornos IoT. La base de datos que vamos a ver a continuación es MongoDB y el siguiente video va a proceder a cómo es la creación de una base de datos para poder utilizarla dentro de nuestro entorno en no-read. Lo primero es ingresar al siguiente link mongodb.com e ir a la opción sigain o loguearse. En caso de que tengan una cuenta pueden ingresar su nombre de usuario y contraseña o registrarse o iniciar un sesión con Google y en caso que no tengan dan a la opción de registrarse y completan los siguientes datos. En nuestro caso como ya contamos con una cuenta de correo electrónico y una cuenta dentro de MongoDB damos a inicio de sesión y esta es nuestra gestora de base de datos. Lo primero que tenemos que hacer es crear una nueva organización donde vamos a alojar nuestra base de datos o a la que va a pertenecer nuestra base de datos dentro de la opción View All Organizations. Creamos una nueva organización. El nombre va a ser ejemplo UGR3. Seleccionamos la opción MongoDB Atlas. En esta opción nosotros podemos invitar miembros y brindar permisos a otros usuarios de MongoDB y en la opción quién va a ser nuestro organizador, seleccionamos nuestra cuenta como administrador. Creamos nuestra organización. Lo siguiente es crear un nuevo proyecto. ¿Cuál va a ser el nombre de nuestro nuevo proyecto? Donde vamos a alojar la base de datos dentro de nuestra organización va a ser en este clases VD UGR 20-25. Podemos seleccionar algunas etiquetas en caso de que requeramos o podemos dejar sin ninguna etiqueta. Eso es opcional. Una vez que damos al botón siguiente nosotros podemos invitar a personas dentro de nuestro proyecto y anexarlas en este ringlon y podemos brindarle el tipo de perfil que quiera. En nuestro caso va a ser nuestro usuario, el administrador. Damos botón a crear proyecto. Una vez que creamos nuestro proyecto vamos a crear nuestra clasper. En nuestra clasper nosotros vamos a poder decir qué tipo de base de datos queremos utilizar. A fines de la cátedra vamos a seleccionar la opción Free que nos va a permitir un almacenamiento de 512 megas con una RAM y virtual CPU compartida. Podemos darle nombre a nuestro clasper. En este caso va a ser clasper UGR 3 y vamos a decir dónde vamos a almacenar nuestra información. ¿Qué tipo de servidor? ¿Un Azure, Google Cloud o Amazon Web Service? Damos la opción a crear desarrollo y nos va a aparecer la opción de cuáles van a ser el usuario y contraseña para ingresar a nuestra base de datos. Estas dos opciones que vemos acá son necesarias. Debemos guardarlas. En un blog de notas guardamos el usuario. Y la contraseña. Esto es opcional. Podemos usar la contraseña por defecto o crear una nuestra. Nuestro caso va a ser Hola123. Una vez que ya tenemos nuestro usuario y contraseña guardamos nuestras credenciales y procedemos a elegir nuestro método de conexión. Tenemos que darle la opción a crear nuestro usuario en la base de datos. Una vez que ya tenemos el usuario creado procedemos a elegir el método de conexión. En la opción de drivers nosotros buscamos la opción de Node.js y el tipo de versión. Dejamos 6.7 en adelante y configuramos también la opción de cómo instalar nuestros nodes dentro de Node.js. Damos OK y ya tenemos configurada nuestra base de datos. El siguiente video va a tratar de hacer la conexión entre nuestro entorno de Node.js y la base de datos de MongoDB. Eso es todo.
