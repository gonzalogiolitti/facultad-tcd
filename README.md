# Tecnicatura en Ciencia de Datos - UGR

Material de cursada de 2° Año descargado y procesado del aula virtual (Moodle) de la UGR
con [ugr-downloader](https://github.com/gonzalogiolitti/ugr-downloader).

> **Nota:** repositorio de uso personal y académico. Contiene apuntes, transcripciones y
> resúmenes generados a partir del material de clase para estudio propio.

## Contenido

Los apuntes, PDFs y presentaciones originales se convierten a texto/Markdown apenas se
descargan (los videos se transcriben con Whisper); este repo versiona ese contenido ya
convertido, no los archivos originales pesados. Por materia, además, se generan con la API
de Claude:

- **`_INFO_MATERIA.md`**: objetivo de la materia, enfoque de la cátedra, metodología de
  evaluación, bibliografía y docentes.
- **`_RESUMEN_CONTENIDO.md`**: índice de contenidos por unidad/sección, con fecha, temas
  clave y resumen de cada archivo de clase.

## Estructura de carpetas

```
2do Anio/
├── BASES DE DATOS/
│   ├── General/
│   ├── Unidad 0/
│   └── Unidad 1/
├── DATOS Y ALGORITMOS/
│   ├── Contenido/
│   └── General/
├── ESTADÍSTICA E INFERENCIA/
│   ├── Grabaciones clases de consulta/
│   └── Unidad 1/
├── LABORATORIO DE DATOS/
│   ├── General/
│   └── Unidad 1/ ... Unidad 5/
├── MATERIA ELECTIVA A/
│   ├── General/
│   ├── Grabaciones sincrónicos/
│   ├── Trabajo practico integrador/
│   └── Unidad 1/, Unidad 2/
└── PRÁCTICA PRE-PROFESIONAL I/
    ├── General/
    └── Segundo Momento/
```

Cada materia tiene, en su raíz, `_INFO_MATERIA.md` y `_RESUMEN_CONTENIDO.md`; el resto de
las carpetas reflejan las unidades/secciones tal como están organizadas en el aula virtual.
