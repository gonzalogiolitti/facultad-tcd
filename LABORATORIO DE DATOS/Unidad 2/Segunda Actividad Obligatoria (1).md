Tecnicatura en Ciencia de Datos 
Laboratorio de Datos 
Segunda Actividad Obligatoria 
Análisis Exploratorio de Datos (DEA) 
En la Primera Actividad Obligatoria cada equipo definió un desafío de gestión a resolver, 
identificó un actor concreto que debe tomar una decisión y seleccionó uno o más conjuntos 
de datos que podrían contribuir a abordar dicho desafío. 
En esta segunda actividad deberán avanzar sobre el mismo caso de trabajo y realizar un 
Análisis Exploratorio de Datos (DEA) sobre los datasets seleccionados.El objetivo de esta 
actividad es conocer, explorar, comprender y caracterizar los datos antes de avanzar hacia 
análisis más complejos, identificando patrones, distribuciones, relaciones, valores atípicos, 
datos faltantes y posibles problemas de calidad. 
Vale aclarar que, previamente, en caso de que sea necesario realizar correcciones o ajustes 
respecto de la Primera Actividad Obligatoria, estos deberán ser realizados antes de 
comenzar con la segunda parte.  
El análisis deberá estar orientado al desafío planteado por el equipo: no se busca 
únicamente describir los datos, sino comenzar a identificar qué información resulta relevante 
para el problema planteado 
Para esta segunda actividad cada equipo deberá entregar:  
-​
Un archivo PDF en donde se resuma todo el DEA. En caso de realizar un 
dashboard, también deberán entregar el mismo. Este deberá contener: 
○​ descripción de los datos, de los datasets y composición de los mismos. 
○​ principales decisiones tomadas durante la preparación; 
○​ análisis realizado; 
○​ visualizaciones principales; 
○​ hallazgos encontrados; 
○​ problemas o limitaciones detectadas. 
A modo de guía, les dejamos un paso a paso de como ir realizando un DEA bien 
desarrollado, ordenado y completo 
1. Preparación de los datos 
●​ Cargar los datasets seleccionados (en formato .xlsx o .csv) 
●​ Identificar las fuentes y registrar su procedencia. 
●​ Describir brevemente cada conjunto de datasets (cómo están compuestos, en qué 
consiste el dataset) 
●​ Identificar la cantidad de registros y variables.

●​ Identificar los tipos de datos de las variables. 
●​ Revisar y documentar valores faltantes. 
●​ Detectar posibles registros duplicados. 
●​ Identificar posibles errores o inconsistencias en los datos. 
●​ Realizar las transformaciones o tareas de limpieza, en caso de ser necesario, para 
poder realizar el análisis correspondiente.  
2. Análisis 
Realizar un análisis individual de las principales variables del dataset. 
Según el tipo de variable, podrán utilizar, entre otros: 
●​ Tablas de frecuencia. 
●​ Medidas de tendencia central. 
●​ Medidas de dispersión. 
●​ Mínimos y máximos. 
●​ Cuartiles y percentiles. 
●​ Histogramas. 
●​ Gráficos de barras. 
●​ Boxplots. 
●​ Mapas. 
●​ Otros recursos gráficos que resulten pertinentes. 
Deberán justificar qué variables fueron seleccionadas para este análisis y qué información 
relevante permiten observar en relación con el desafío planteado. 
3. Análisis de relaciones entre variables 
Explorar posibles relaciones entre las variables relevantes para el problema. 
Según las características de los datos, podrán utilizar: 
●​ Tablas de contingencia. 
●​ Gráficos de dispersión. 
●​ Comparaciones entre grupos. 
●​ Matrices de correlación. 
●​ Gráficos temporales. 
●​ Análisis geográfico, cuando corresponda. 
●​ Otras técnicas exploratorias pertinentes. 
No es necesario aplicar todas estas técnicas. Cada equipo deberá seleccionar aquellas 
que sean adecuadas para sus datos y para el desafío que está abordando. 
4. Identificación de patrones y problemas 
A partir del análisis realizado, deberán identificar: 
●​ Patrones o tendencias relevantes. 
●​ Diferencias entre grupos o categorías.

●​ Relaciones entre variables. 
●​ Valores atípicos. 
●​ Datos faltantes o problemas de calidad que puedan afectar el análisis. 
●​ Variables que podrían resultar especialmente relevantes para el desafío. 
●​ Resultados inesperados o que requieran una investigación posterior. 
5. Hallazgos y relación con el desafío 
El DEA deberá finalizar con una síntesis de los principales hallazgos exploratorios. 
Cada equipo deberá responder: 
Sobre el desafio planteado:  
1.​ ¿Cómo responden los datos al desafío planteado? 
2.​ ¿Qué decisión sugerirían tomar en base a los datos analizados? 
Sobre el análisis exploratorio: 
3.​ ¿Qué aprendieron sobre los datos a partir del análisis? 
4.​ ¿Qué patrones o relaciones encontraron? 
5.​ ¿Qué variables parecen ser más relevantes para el desafío planteado? 
6.​ ¿Encontraron algún problema de calidad o limitación en los datos? 
7.​ ¿Qué preguntas nuevas surgieron a partir de la exploración? 
Herramientas 
El análisis podrá realizarse utilizando la herramienta que el equipo considere adecuada. 
Podrán utilizar, entre otras: 
●​ Python 
●​ R / RStudio 
●​ Herramientas de visualización o dashboards 
●​ O una combinación de herramientas. 
La herramienta utilizada no será el objetivo principal de la actividad. Se evaluará 
especialmente la calidad del proceso exploratorio, la interpretación de los resultados y su 
relación con el desafío planteado. 
Las visualizaciones deberán ser seleccionadas en función de la información que se busca 
comunicar. 
No se espera una gran cantidad de gráficos, sino gráficos que: 
●​ sean pertinentes para las variables analizadas; 
●​ permitan interpretar los datos con claridad; 
●​ tengan títulos y etiquetas adecuados; 
●​ permitan identificar patrones o relaciones; 
●​ estén acompañados por una interpretación.
